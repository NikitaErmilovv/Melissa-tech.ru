# Данные Aliento

| Файл | Назначение |
|------|------------|
| **`aliento.json`** | Живая база на сервере/локально (ученики, абонементы, расписание). **Не в git.** |
| **`aliento.initial.json`** | Снимок для **первого** запуска: если `aliento.json` нет, копируется отсюда. |

На Timeweb всё пишется в `data/aliento.json` внутри контейнера. Локальный файл на твоём ПК и серверный — **разные**; в git уезжает только `aliento.initial.json`.

Перед деплоем: скачай `aliento.json` с сервера в бэкап. После деплоя на пустой диск подтянется `aliento.initial.json` из репозитория.

Обновить стартовый снимок с локали:

```bash
cp data/aliento.json data/aliento.initial.json
```
