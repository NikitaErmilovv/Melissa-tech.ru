Alvion — доступ для проверки сайта
=================================

КАК ЗАПУСТИТЬ
1. Откройте папку alvion-nizhnevartovsk.
2. Дважды нажмите start.bat.
3. Браузер откроет сайт сам: http://127.0.0.1:8102/
4. Окно чёрного терминала не закрывайте, пока смотрите сайт.
   Для остановки: Ctrl+C в этом окне.

Если браузер не открылся — вручную перейдите по адресу выше.

Нужен установленный Python 3. Если его нет: https://www.python.org/downloads/
(при установке отметьте “Add python.exe to PATH”).


ТЕСТОВЫЕ АККАУНТЫ

Клиент (личный кабинет)
  Страница входа: http://127.0.0.1:8102/login.html
  Логин:    client@alvion.ru
  Пароль:   client123
  После входа открывается «Кабинет»: запись, заявки, профиль.

Администратор (админка)
  Страница входа: http://127.0.0.1:8102/login.html
  Логин:    admin@alvion.ru
  Пароль:   alvion123
  После входа открывается «Админка»: заявки, клиенты, статусы.

Перед сменой аккаунта нажмите «Выйти».

- Главная, услуги, работы, о студии, контакты
