# Регистрация студии (самообслуживание)

## Поток для владельца

1. **Шаг 1** — имя, email, телефон, пароль → `auth.startRegistration` → код на email (или `devCode` на экране без Resend).
2. **Шаг 2** — ввод 6-значного кода → `auth.verifyRegistrationCode`.
3. **Шаг 3** — название студии, город, адрес, ИНН (опц.) → `auth.completeRegistration` → **сразу личный кабинет** с демо-данными.

**Одобрение суперадмином для входа не требуется.** Суперадмин получает **уведомление на email** (когда настроен Resend).

## Суперадмин

- По-прежнему: **создать организацию**, **выдать доступ** вручную (`issueStudio`, `issueStaff`).
- Очередь `registration_requests`: саморегистрации помечаются **approved** автоматически.

## Демо-данные

- После саморегистрации подставляются примеры заказов/клиентов.
- На дашборде: **«Выключить демо-данные»** → `desk.disableDemoSample`.

## Старый сценарий

`auth.register` + ссылка `/verify-email` + ручное одобрение — оставлен для совместимости, UI `/register` переведён на новый поток.
