## Локальный запуск

**Windows:** двойной клик по `start.bat` или в командной строке из папки проекта:

```bat
start.bat
```

**Linux / macOS:**

```bash
python3 server.py
```

Сайт: http://127.0.0.1:8090/

Порт по умолчанию — **8090** (см. `server.py`). На Windows при блокировке брандмауэра можно запустить `open-firewall-8089.bat` или `open-firewall-8083.bat` из соседних шаблонов monorepo, при необходимости скопировав под порт 8090.
