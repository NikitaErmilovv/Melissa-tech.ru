# Brilliant auto — Благовещенск

Боевой сайт: **https://brilliant-auto-detailing.ru**

Статичный сайт (HTML/CSS/JS). Корень проекта = корень сайта (`index.html` в корне).

## Timeweb Apps

1. Создайте **статичное приложение**.
2. Подключите этот репозиторий (ветка `master`, корневая папка `/`).
3. В доменах приложения добавьте `brilliant-auto-detailing.ru` и `www` при необходимости.
4. У регистратора домена укажите DNS, которые покажет Timeweb.

Демо на melissa-tech.ru не трогаем — это отдельная копия для клиента.
