# Aliento: починить быстрый вход на Timeweb

**Проблема:** на `nikitaermilovv-aliento-6aa4.twc1.net` до сих пор **старая сборка** — нет кнопок «Войти как …», только текст «Демо-доступы». Агент **не может `git push` в `NikitaErmilovv/Aliento`** (403).

**Кнопки никто не отключал** — их просто **нет в задеплоенном коде**.

## Что сделать (5 минут)

1. На своём ПК открой репозиторий [Aliento](https://github.com/NikitaErmilovv/Aliento).
2. Скопируй файлы из этой папки в проект (или влей ветку `cursor/aliento-login-cabinet-fix-8ce1` из cloud-агента).
3. В Timeweb → переменные: **`SESSION_SECRET`** (длинная строка, не менять при редеплоях).
4. `git push origin main` → дождись автодеплоя.

## Признак успешного деплоя

На `/login` есть блок **«Быстрый вход»** с кнопками **«Войти как администратора»** и т.д.
