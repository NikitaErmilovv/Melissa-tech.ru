# Fantastika: открыть с телефона (та же сеть)

Cloud Agent в Cursor крутится **на удалённом сервере**. Телефон **не** увидит его `127.0.0.1` — даже если раздаёте интернет с телефона на ноутбук.

Нужно запустить сайт **на ноутбуке**, где лежит актуальный код.

## 1. Код на ноутбуке

```bash
git clone https://github.com/NikitaErmilovv/Melissa-tech.ru.git
cd Melissa-tech.ru
git pull origin master
cd fantastika-home174-lazurny
```

(Если репозиторий уже есть — только `git pull` в `Melissa-tech.ru`.)

## 2. Запуск сервера

```bash
python server.py
```

В консоли появятся адреса. Сервер слушает **все интерфейсы** (`0.0.0.0:8135`).

## 3. IP ноутбука в сети телефона

- **Windows:** `ipconfig` → адаптер, через который ноутбук получает интернет с телефона (часто «Беспроводная сеть» или USB-модем) → **IPv4**, например `192.168.43.2`.
- **macOS:** Системные настройки → Сеть или `ipconfig getifaddr en0`.

## 4. На телефоне

В браузере (лучше **та же Wi‑Fi / раздача**, не мобильный интернет отдельно):

`http://ВАШ_IP_НОУТБУКА:8135/`

Пример: `http://192.168.43.2:8135/`

## 5. Если не открывается

- Ноутбук и телефон в **одной** сети (раздача с телефона включена, ноутбук к ней подключён).
- **Брандмауэр Windows:** разрешить входящие для Python на порт **8135** (или временно отключить для проверки).
- Антивирус не блокирует локальную сеть.
