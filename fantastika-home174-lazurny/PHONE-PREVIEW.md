# Fantastika: открыть с телефона (та же сеть)

Cloud Agent в Cursor крутится **на удалённом сервере**. Телефон **не** увидит его `127.0.0.1` — даже если раздаёте интернет с телефона на ноутбук.

Нужно запустить сайт **на ноутбуке**, где лежит актуальный код.

## 1. Код на ноутбуке

```bash
git clone https://github.com/NikitaErmilovv/Melissa-tech.ru.git
cd Melissa-tech.ru
git pull origin master
cd fantastika-home174-lazurny
```

(Если репозиторий уже есть — только `git pull` в `Melissa-tech.ru`.)

## 2. Запуск сервера

```bash
python server.py
```

В консоли появятся адреса. Сервер слушает **все интерфейсы** (`0.0.0.0:8135`).

## 3. IP ноутбука в сети телефона

- **Windows:** `ipconfig` → адаптер, через который ноутбук получает интернет с телефона (часто «Беспроводная сеть» или USB-модем) → **IPv4**, например `192.168.43.2`.
- **macOS:** Системные настройки → Сеть или `ipconfig getifaddr en0`.

## 4. На телефоне

В браузере (лучше **та же Wi‑Fi / раздача**, не мобильный интернет отдельно):

`http://ВАШ_IP_НОУТБУКА:8135/`

Пример: `http://192.168.43.2:8135/`

## 5. Если не открывается (частые причины)

1. **Сервер не на ноутбуке** — в Cloud Agent сайт уже крутится, но телефон его не видит. На ноуте обязательно: `cd fantastika-home174-lazurny` → `python server.py` (окно не закрывать).
2. **На ноуте сначала** откройте http://127.0.0.1:8135/ — если не работает, с телефона тоже не будет.
3. **Не тот IP** — `192.168.137.x` часто от «Мобильного хот-спота Windows» или виртуального адаптера, а не от раздачи **с телефона**. При раздаче с **Android** у ноутбука часто `192.168.43.x`, с **iPhone** — `172.20.10.x`. Берите IPv4 у адаптера **«Беспроводная сеть»**, когда ноут подключён к раздаче телефона.
4. **Брандмауэр** — запустите `serve-phone-windows.bat` (добавит правило для порта 8135) или от админа:
   `netsh advfirewall firewall add rule name="Fantastika8135" dir=in action=allow protocol=TCP localport=8135`
5. Телефон в **той же** сети (не только LTE в браузере).
