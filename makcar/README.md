# MakCar — кузовной ремонт и покраска (Омск)

Статический сайт MakCar (HTML/CSS/JS).

## Локальный запуск

**Проще всего:** дважды кликнуть `start.bat` в папке `makcar`.

Или в терминале:

```bash
cd makcar
python -u server.py
```

Открыть: http://127.0.0.1:8087/

> Запускать нужно **из папки `makcar`**, не из корня проекта.

Статика без Python: `python -m http.server 8087` (рейтинг 2GIS останется 5.0).
