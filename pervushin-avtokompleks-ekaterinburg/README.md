# Первушин

## Локальный просмотр

Из **этой папки** (не из корня репозитория и не через `file://`):

```bash
cd pervushin-avtokompleks-ekaterinburg   # если вы в корне Melissa-tech.ru
python3 server.py
```

Открыть в браузере: **http://127.0.0.1:8124/** — именно главная `index.html`.

Если правки не видны:

1. `git pull` (изменения только после обновления репозитория).
2. Жёсткое обновление страницы (Ctrl+Shift+R / Cmd+Shift+R).
3. Убедиться, что порт **8124** и папка **pervushin-avtokompleks-ekaterinburg** (другие сайты в репо — другие порты).
4. Блок «Где мы находимся»: кнопки **2ГИС** и **Яндекс Карты**, рейтинги — на всех страницах; в футере — обе ссылки.

Прод: https://melissa-tech.ru/pervushin-avtokompleks-ekaterinburg/ (обновляется после push в `master` и деплоя Timeweb).
