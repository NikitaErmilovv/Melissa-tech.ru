# Restyle — студия детейлинга (Сургут)

Статический сайт Restyle (HTML/CSS/JS).

## Локальный запуск

**Проще всего:** дважды кликнуть `start.bat`.

Или в терминале:

```bash
cd restyle-surgut
python -u server.py
```

Открыть: http://127.0.0.1:8094/
