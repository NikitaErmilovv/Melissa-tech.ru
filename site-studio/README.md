# Melissa Site Studio

Локальный редактор **только новых** сайтов. Готовые папки в репозитории (`ozero-kaldy-sary`, …) **не открываются** и **не коммитятся**.

## Запуск

`start.bat` → http://127.0.0.1:3847

## Как пользоваться

1. **Стартовый экран** — выберите шаблон (**River Home** или **Fantastika**), введите slug, **«Создать черновик»**.
2. Черновик лежит в `site-studio/workspace/<slug>/` (не в Git, пока не опубликовали).
3. Редактируете → **Применить** → **Открыть локально**.
4. **Опубликовать на GitHub** — копия уходит в корень репо `<slug>/`, один commit + push, ссылка на прод.

Шаблон (`river-home-terentievo` и т.д.) **только читается** как эталон при создании.

## Git

На GitHub попадает **только** папка сайта, который вы опубликовали из студии. `site.config.json` в прод **не копируется**.

Если раньше студия трогала готовые сайты — откат: `git restore <папка>`.
