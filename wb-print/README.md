# Печатный стол

Панель для магазина на Wildberries: покупатель сам пишет в чат, бот называет номер заказа и просит фото по артикулу. Файлы сразу ложатся в папку, из которой можно печатать.

Один общий стол на офисный компьютер. Разделения на аккаунты нет.

## Запуск

```bash
cd wb-print
npm install
cp .env.example .env.local   # по желанию: PANEL_PASSWORD=ваш_пароль
npm run dev
```

Панель открывается на [http://127.0.0.1:8341](http://127.0.0.1:8341).

### Пароль на сервере

Скопируйте `.env.example` в `.env.local` (или задайте переменную окружения на хостинге) и укажите `PANEL_PASSWORD`. Браузер один раз спросит логин и пароль: **логин может быть любым**, проверяется только пароль. Без `PANEL_PASSWORD` панель доступна всем, кто знает адрес — для офиса лучше пароль или доступ только по VPN/туннелю (Cloudflare Tunnel, Tailscale).

GitHub Pages и чистый статический хостинг **не подходят**: заказы и файлы лежат на диске в `data/`. Нужен Node-сервер с постоянным томом (офисный ПК, VPS, Timeweb App Platform, Railway/Render с volume). Репозиторий можно держать на GitHub бесплатно; деплой — `git pull` на машине, где крутится `npm run build && npm run start`.

Без токена уже есть примеры: альбом 12 из 50, стикеры в печати, отменённый заказ и ссылка на диск. Свои артикулы заводятся во вкладке «Артикулы». Тексты бота правятся во вкладке «Тексты».

Чтобы начать заново, остановите сервер и удалите папку `data`.

## Как отвечает бот

Писать первым нельзя. Папка появляется, когда покупатель нажал «написать продавцу» и отправил сообщение.

Для 3D-стикеров бот сразу просит прислать фотографии в чат и лучше квадратом: «Пришлите, пожалуйста, шесть фотографий, которые хотели бы напечатать». Если фото не квадратное, в папку кладётся квадрат с левого верхнего угла, по самой большой стороне, которая помещается. Ссылку на диск для стикеров не берём. Для печати фотографий в первом письме остаётся выбор: файлы в чат или ссылка, и эти кадры не обрезаются.

Число файлов берётся из карточки артикула. Заведены **3D-стикеры** (1, 2, 4, 6, 8, 12 макетов) и **печать 15×10 / Polaroid** по nmId WB: 25, 50, 100, 200 фото (Photo25…Photo200, Polaroid25…Polaroid200). Стикеры — в `data/files/stickers/`, фото — в `data/files/photos/`. Пока файлов меньше, бот после паузы (по умолчанию 2 минуты) и затем каждые 4 минуты пишет, сколько ещё не хватает. Что уже пришло, сохраняется сразу. Когда набор полный, бот один раз пишет, что фотографии приняты. Заменить их можно в течение 30 минут: сначала слово «замена», затем новые файлы. Без этого слова новые фотографии не сохраняются.

Ссылка на Яндекс Диск или файл Google Диска — только для печати фотографий. Картинка скачивается в папку заказа, если диск открыт по ссылке. Документы и программы не сохраняются. Ссылка остаётся, её можно скачать кнопкой ещё раз.

Отмена на WB помечает папку «отменён» и останавливает напоминания. Покупателю при отмене бот не пишет. Если папка уже «готово», статус печати не сбрасывается.

## Токен

В настройках вставляется токен продавца. Нужны категории **Чат с покупателями** и **Маркетплейс**: первая для диалога, вторая для номера заказа и отмен. Токен пишется в `data/db.json` и в git не попадает.

Старую переписку и заказы, по которым никто не писал, не выгружаем. После включения «Ответы покупателям» на стол попадают только новые сообщения: папка создаётся, когда покупатель сам написал.

## Папки

Стикеры лежат в `data/files/stickers/дата/номер_2шт_артикул/`. Фото, когда появятся свои карточки, — в `data/files/photos/`. На столе заказы разделены: сначала 3D-стикеры, затем фото. Статусы печати: новый, в печати, готово, брак, отменён. У заказа есть архив и печать из браузера.

Очистка только вручную: готовые, отменённые и брак старше 7 дней. Новые и те, что в печати, не трогаются.
